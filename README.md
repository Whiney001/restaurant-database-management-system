# Restaurant Database Management System (Python + SQLite)

A Python-based command-line system to store restaurant profiles, menus, dietary options, and reviews using SQLite. Provides CRUD features for structured restaurant data management.

## Features
• Add, update, and delete restaurant information  
• Store and filter menus and dietary tags  
• Secure parameterized SQL queries  
• Persistent local database  
• Menu-driven CLI interface

## Technologies Used
• Python  
• SQLite

## Key Learning Outcomes
• Relational database design  
• CRUD operations with structured data  
• Secure parameterized SQL usage  
• CLI-based interaction flow
